- Python 3.x
- Basic understanding of data structures and algorithms
- Familiarity with LeetCode platform

### Clone the Repository

```bash
git clone https://github.com/AmanBadola01/Problem-Solving-Journey.git
cd Problem-Solving-Journey
```

## 💡 How to Use

1. **Browse Problems**: Navigate through the numbered problem folders
2. **Read Solutions**: Each folder contains the solution implementation
3. **Understand Approach**: Review the problem explanation and approach
4. **Learn Complexity**: Check time and space complexity analysis
5. **Practice**: Try solving problems on [LeetCode](https://leetcode.com) before checking solutions

### Suggested Learning Path

Start with **fundamental concepts**:
1. Two Sum (Array basics)
2. Linked List problems (Data structure manipulation)
3. SQL problems (Database queries)

Then move to **advanced topics** based on your weak areas.
